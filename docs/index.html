Listing Check

Compares what a seller put in the MLS with what each site shows. Change a value in the grid and the check runs again.

ⓘ

Prototype on made-up listings. No real MLS data. Exact fields are checked with plain rules, no AI model. It only flags problems. A person decides what to fix.

How it works
  • The MLS record is the source of truth. Each site is compared to it, field by field.
  • Formats are cleaned first, so "$725,000", "725000", "Lane" and "Ln" are not errors.
  • Status and price rank critical. Address, beds and baths rank high. Square footage is medium. Description text is low.
  • Seller instructions are separate rules: a hidden address must not show, and a listing must not appear on a site the seller did not allow.
  • If the MLS changed in the last 15 minutes, a difference is marked "recheck" because a site may not have caught up.
  • A bad value in the MLS record is flagged and skipped. The rest of the listing is still checked.
